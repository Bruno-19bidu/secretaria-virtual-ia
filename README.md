# 🤖 Secretária Virtual com Inteligência Artificial

Sistema de automação de atendimento desenvolvido com foco em Inteligência Artificial, automação de processos e integração de APIs.

## 🚀 Funcionalidades

- Agendamento automático
- Cancelamento de compromissos
- Consulta de compromissos
- Interpretação de linguagem natural com IA
- Fluxo automatizado utilizando n8n

## 🛠️ Tecnologias utilizadas

- n8n
- APIs REST
- JSON
- IA / LLMs
- NLP

## 🧠 Objetivo

Demonstrar a aplicação prática de Inteligência Artificial em automação de processos e atendimento automatizado.
